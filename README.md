Advanced Android Developer Utility App
​This application is an all-in-one, power-user utility designed specifically for Android 12 and higher. It bridges the gap between low-level system modifications and convenient command-line execution, providing a centralized dashboard for device management and system tweaking.
​Key Features & Menu Overview
​⚡ Root Management:
Directly manage superuser privileges, control app-specific binary access, and monitor root request logs safely and efficiently on modern Android architectures.
​🔍 Root Checker:
Instantly verify root access status, check binary paths (su), and validate SELinux enforcement modes (Enforcing/Permissive) to ensure your system modifications are correctly applied.
​🔓 OEM Unlocking:
Quickly check the OEM unlocking toggle state and access direct shortcuts to developer options required for bootloader manipulation.
​⚙️ Bootloader Status:
Inspect the current bootloader security state (Locked/Unlocked), device critical flags, and get detailed hardware state diagnostics.
​🧩 Shizuku Integration:
Leverage Shizuku service binding to execute high-privilege system APIs and commands without needing a full traditional root session, ensuring better compatibility with modern apps.
​💻 Termux Companion:
Seamlessly launch and interface with Termux environments, allowing you to run shell scripts, GNU utilities, and advanced terminal automation directly from the app dashboard.
